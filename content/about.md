杨浩，华侨大学制造工程研究院在读博士生。研究方向是**钎焊金刚石线锯**：把金刚石磨粒焊到细钢丝上，用来切蓝宝石、氮化硅这类又硬又脆的半导体材料。平时在实验室和 SEM（扫描电镜）打交道，也在写 Python，把那些重复的、容易出错的活交出去。

## 在做的

- 钎焊金刚石线锯的上砂工艺、线锯制备与切割性能——学位论文的主体
- 给 Claude Code 写的小工具：[claude-statusline](https://github.com/yanghaod2278827/claude-statusline)（把花在第三方 API 上的钱算准）、[claude-worklog-dida](https://github.com/yanghaod2278827/claude-worklog-dida)（把每天做过的事自动变成已完成的任务）

## 这个站

Hugo 构建，托管在 GitHub Pages。写两类东西：一类是踩过的坑——那些查过一次还会再查的；另一类是「这个重复劳动能不能交给程序」的记录。首页的 star 数每天凌晨由脚本从 GitHub 拉一次，文章数由 Hugo 自己数，都不是手填的。
