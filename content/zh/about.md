我平时写一些小工具，全部开源在 [GitHub](https://github.com/yanghaod2278827)。它们大多来自同一个动机：**某件重复劳动做烦了，就写个脚本让它消失**。

## 在做的项目

- **[claude-statusline](https://github.com/yanghaod2278827/claude-statusline)** — 给 Claude Code 用的成本状态栏：第三方 API 的峰谷计价、余额、缓存命中率，一条命令装好
- **[claude-worklog-dida](https://github.com/yanghaod2278827/claude-worklog-dida)** — 把一天做过的事从 Claude 会话和文件时间戳里还原出来，写成滴答清单的已完成任务，再同步进 Obsidian 日记

## 这个站

这个站本身也是开源的，在[项目](/projects/)页里有它自己的一条：Hugo + PaperMod 构建、GitHub Actions 部署，页面上的数字全部由脚本从 GitHub 拉取，没有手填的。分类与标签计数、文章数也是构建时算的。源码在 [yanghaod2278827.github.io](https://github.com/yanghaod2278827/yanghaod2278827.github.io)。

翻旧文可以走 [归档](/archives/)（按年份）、[标签](/tags/)或[搜索](/search/)（纯前端，索引在构建时生成）。
