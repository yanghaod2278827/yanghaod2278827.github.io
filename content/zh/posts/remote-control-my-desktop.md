需求很简单：出门时用手机看看电脑上跑到一半的东西、顺手发几条命令。折腾下来结论是**两条腿走路**——一条为了好看好用，一条为了在主通道挂掉时还能进去。

## 主通道：ToDesk

买会员主要为了两个功能：**隐私屏**（连上后本机显示器黑屏，防止旁人看到）和**虚拟屏**（合盖后仍然有一个可操作的桌面）。对"人在外面、机器在家里"的场景，这两个几乎是刚需。

缺点是依赖厂商服务器，网络一差就掉线。

## 备胎：Tailscale + SSH

Tailscale 把手机和电脑放进同一个虚拟内网，各自有固定 IP（本机是 `100.x.x.x` 这种）。然后只要电脑开着 SSH 服务，手机上一个 SSH 客户端（Termius 之类）就能直接登进来跑命令。

好处是**完全不走第三方桌面协议**，带宽需求极低，隧道在后台一直挂着。坏处是只能敲命令、看不到桌面——但"检查任务有没有跑完""重启一个脚本"这类事，本来就只需要命令。

Windows 上装 OpenSSH 服务端的坑：

1. 系统自带的 `OpenSSH Server` 是可选的 Windows 功能，得先装上
2. 装完服务默认**不启动**，要 `Set-Service sshd -StartupType Automatic` 再 `Start-Service sshd`
3. 防火墙要放行 22 端口（装功能时通常会自动加规则，但被组策略关掉时不会）
4. 默认只允许**管理员组密钥登录**，密码登录被注释掉了，要在 `sshd_config` 里显式打开

## 真正难的部分：让它一直醒着

软件装好只是开始。笔记本的默认行为是"合盖休眠"，一休眠什么都连不上。要改的是一整套电源策略：

| 设置 | 改成 | 为什么 |
|:--|:--|:--|
| 合盖动作 | 不采取任何操作 | 否则一盖就断 |
| 插入电源时进入待机 | 从不 | |
| 关闭显示器 | 从不 | 显示器关了不影响，但有些驱动会连带挂起 |
| Windows 更新 | 暂停 | 半夜自动重启会打断一切 |

还有一个反向需求：**干活的时候不能被休眠打断**。如果电脑正在跑长任务（比如编译、转码），要防止它因为"空闲"而睡过去。做法是一个小的守护脚本，定期检查有没有活跃进程在吃 CPU 或 I/O，有就续期唤醒锁，空闲一段时间后才释放。

这里有个容易踩的判断错误：**"进程存在"不等于"在干活"**。常开着的编辑器、终端可能有七八个进程，全算活跃的话唤醒锁永远不会释放。改成看**增量**——15 秒内 CPU 时间涨了 0.45 秒以上、或者 I/O 涨了 5 MB 以上，才算真正在用。只判 CPU 会漏掉下载这类 I/O 密集任务。

## 最后一个物理问题

合上盖子后，**Wi-Fi 天线被机身挡住**，信号从满格掉到两三格，到路由器的丢包率和延迟都上去了。这个在软件层面没法解决，只能：把电脑放在信号好的位置、或者接受"合盖后远程会卡"。

这也是为什么要有第二条腿——ToDesk 掉线时，SSH 那条轻量隧道往往还活着。

---

回头看，整套方案的复杂度几乎全在"让它保持可连接"上，装软件只占很小一部分。远程控制本质是个**运维问题**，不是软件问题。
