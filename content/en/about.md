I write small tools and open-source all of them on [GitHub](https://github.com/yanghaod2278827). They tend to start the same way: **something repetitive got annoying enough that I scripted it away**.

## Projects

- **[claude-statusline](https://github.com/yanghaod2278827/claude-statusline)** — a cost-aware status line for Claude Code on third-party APIs: peak/off-peak pricing, balance, cache hit rate, installed with one command
- **[claude-worklog-dida](https://github.com/yanghaod2278827/claude-worklog-dida)** — reconstructs what a day actually did from Claude transcripts and file timestamps, writes it back as completed tasks and syncs it into an Obsidian diary

## This site

The site is open source too and has its own card on the [Open Source](/en/projects/) page: Hugo + PaperMod, deployed by GitHub Actions, every number fetched by a script from GitHub; article, category and tag counts are computed at build time. Source: [yanghaod2278827.github.io](https://github.com/yanghaod2278827/yanghaod2278827.github.io).
